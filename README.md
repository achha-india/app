# Ачча! Разговорник для Индии

Веб-приложение для русскоязычных туристов в Индии: фразы по этапам поездки, ответы, которые можно услышать от индийцев, чтение кириллицей, озвучка и режим «Показать». После первого открытия работает без интернета.

Адрес: https://achha-india.github.io/app/

## Как устроено

| Файл | Что это |
|---|---|
| `index.html` | Приложение. Собирается из `src/page.html`, вручную не править |
| `src/page.html` | Исходник интерфейса |
| `phrases.json` | Фразы. Выгружается из Google-таблицы |
| `sw.js` | Офлайн-режим: сохраняет приложение, фразы и шрифты на телефоне |
| `manifest.webmanifest`, `icons/` | Установка на главный экран |
| `tools/build.py` | Сборка `index.html` |
| `tools/export.gs` | Скрипт Google-таблицы: меню «Разговорник → Выгрузить JSON» |

## Как обновить фразы

1. Поправить фразы в Google-таблице.
2. В таблице: «Разговорник → Выгрузить JSON». На Google Drive обновится `phrases.json`.
3. Заменить `phrases.json` в этом репозитории.

Телефоны получат новые фразы при следующем открытии приложения с интернетом.

## Как обновить интерфейс

1. Изменить `src/page.html`.
2. Запустить `python3 tools/build.py`.
3. В `sw.js` увеличить `VERSION` (например, `achha-v2`), чтобы телефоны скачали новую версию.
